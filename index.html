          수동 DB 입력

          자동 시트가 없는 채널의 일별 DB를 입력해요. 같은 날짜·채널에 자동 데이터가 생기면 자동이 우선이에요.

          최근 입력 내역

          목표는 시트의 목표 탭(월 | 구분 | 목표DB)에서 읽어요. "어제까지"는 오늘을 뺀 확정 수량이고, 하루 필요량은 남은 수량을 오늘 포함 남은 날 수로 나눈 값이에요. 자동 시트가 없는 채널은 수동DB 탭(일자 | 채널 | DB수) 입력분으로 계산하고, 같은 날짜·채널에 자동 데이터가 생기면 자동 데이터를 우선해요. 위쪽 중복 제외 옵션이 적용돼요.
