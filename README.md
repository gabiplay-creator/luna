# 글로벌랩스 DB 대시보드

구글 시트의 DB를 날짜별·주간·월별·요일별·시간대별로 보고, 채널·비고·META 플랫폼·캠페인별 비율을 확인하는 대시보드입니다.

## 구조

```
index.html   대시보드 화면 (GitHub Pages가 보여주는 페이지)
style.css    디자인
app.js       집계·차트 로직 (기능 추가는 주로 여기서)
config.js    API 주소·토큰 설정
Code.gs      구글 시트에 붙여넣는 데이터 API (GitHub에서는 실행되지 않음, 보관용)
```

데이터 흐름: 구글 시트 → Apps Script 웹 앱(개인정보 제외 JSON) → GitHub Pages 대시보드

## 설정

1. 구글 시트에서 확장 프로그램 → Apps Script를 열고 `Code.gs` 내용을 붙여넣어 저장합니다.
2. 배포 → 새 배포 → 웹 앱. 실행 사용자는 "나", 액세스 권한은 "모든 사용자"로 배포하고 웹 앱 URL을 복사합니다.
3. `config.js`의 `API_URL`에 그 URL을 넣습니다. `ACCESS_TOKEN`을 정했다면 `TOKEN`도 같은 값으로 맞춥니다.

Apps Script 코드를 수정한 뒤에는 배포 → 배포 관리 → 수정(연필) → 버전 "새 버전"으로 다시 배포해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다.

## 채널·그룹

- 시트에 `GL(…)` 형식의 탭(예: `GL(K)`)을 만들면 자동으로 채널로 인식되고, 화면에서는 `K`처럼 짧게 표시됩니다.
- 주력1팀(G, H), 주력2팀(D, B, U)에 없는 채널은 모두 지원군으로 집계됩니다. 그룹 구성은 `app.js` 맨 위 `GROUPS`에서 바꿀 수 있어요.
- 형식은 맞지만 빼고 싶은 탭은 Apps Script `Code.gs`의 `EXCLUDE_SHEETS`에 적고 새 버전으로 배포하세요.
- 새 탭은 날짜 칸(일자·제출일시·날짜 등)과 연락처 칸(연락처·전화번호 등) 이름만 있으면 칸 위치는 상관없습니다. 둘 다 못 찾으면 A열을 날짜로 봅니다.

## 광고비 · CPA

광고비는 매체별 탭(`광고비_구글`, `광고비_메타`, `광고비_틱톡`, 필요하면 `광고비_수동`)에 `일자 | 채널 | 매체 | 광고비 | 갱신시각` 형식으로 쌓이고, 대시보드 API가 `광고비`로 시작하는 탭을 모두 읽어 채널별 CPA를 계산합니다.

- 구글 애즈(G, H, D, B, U): `구글애즈_스크립트.js`를 구글 애즈 → 도구 → 스크립트에 붙여넣고 매시간 실행
- 메타(M), 틱톡(T, K, MT): `광고비연동_AppsScript.gs`를 Apps Script 프로젝트에 새 파일로 추가하고 `setupAdSpendTrigger` 한 번 실행
- 토큰(META_TOKEN, TIKTOK_TOKEN)은 Apps Script의 스크립트 속성에만 저장합니다. 이 저장소에는 절대 올리지 마세요.

### 중복보고(수기 입력) 연동

임시CRM 시트의 `중복보고` 탭에 있는 `GL(○) 광고비` 블록(날짜 | 광고비(VAT포함))을 1시간마다 읽어 `광고비_수동` 탭에 쌓습니다. 원본 블록이 매달 새로 바뀌어도 지난 기록은 `광고비_수동`에 그대로 남아요. 같은 날짜·채널이 API 탭에도 있으면 API 값이 우선이고, API 금액에는 부가세(×1.1)를 곱해 수기 입력과 기준을 맞춥니다.
